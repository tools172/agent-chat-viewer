# 功能路线图

## 体验优化

### 会话导航可拖拽调整宽度
- 类似 TurnNavigator 的拖拽手柄，在 SessionNavigator 右侧边缘
- 拖拽时实时调整宽度，松开后存储到设置
- 可替代当前滑块设置，或两者并存

### 键盘快捷键
- `Ctrl+F` / `Cmd+F` — 聚焦搜索栏
- `Escape` — 关闭设置面板 / 导出对话框
- `↑` `↓` — 在会话列表中切换
- `Ctrl+1/2/3/4` — 切换视图（全部/文件夹/时间线/搜索）

### 导出进度提示
- 导出大文件时显示进度条或 loading 状态
- 导出完成后 toast 提示成功/失败
- 支持取消正在进行的导出

---

## 会话管理

### 会话删除/归档
- 右键菜单增加"删除会话"选项，确认后删除对应 JSONL 文件
- 支持软删除（移到回收站/归档目录）
- 批量选择删除

### 收藏/标记会话
- 会话列表中可收藏/取消收藏
- 收藏的会话置顶或在独立视图中查看
- 数据持久化到 settings.json 或独立文件

### 会话排序增强
- 当前已支持时间/路径/名称/消息数/Agent/大小排序
- 可考虑：最近打开时间排序、自定义排序

---

## 视觉增强

### 暗色模式
- 全局暗色主题切换（跟随系统 / 手动切换）
- Tailwind 的 `dark:` 前缀可原生支持
- 代码块、Markdown 渲染适配暗色

### 多标签页
- 顶部标签栏，支持同时打开多个会话
- 点击会话列表时新建标签而非替换
- 标签可关闭、可拖拽排序

---

## 数据洞察

### 会话统计面板
- 项目维度：总会话数、总消息数
- 时间维度：会话频率趋势图
- Agent 维度：各 Agent 使用占比

### Token 用量估算
- 基于消息内容长度粗略估算 Token 数
- 会话列表显示估算 Token 用量
- 项目/Agent 维度汇总

# 功能路线图

> ✅ = 已完成，🚧 = 进行中，💡 = 计划中

## 已完成的重大功能

### ✅ Cursor AI 编辑器支持
- 从 Cursor SQLite 数据库（`%APPDATA%\Cursor\User\globalStorage\state.vscdb`）直接读取聊天记录
- 自动生成 JSONL 缓存文件，与现有文件型 Provider 架构无缝集成
- 支持新版（`workspaceIdentifier.uri.fsPath`）和旧版（`workspaceProjectDir`）工作目录格式
- 缓存版本机制，格式变更时自动刷新
- 35 个 Rust 单元测试覆盖（解析、序列化、工作目录多级 fallback、路径转换）
- Cursor 数据库锁容错：SQLite 连接失败时跳过刷新，使用已有缓存

### ✅ 合并连发优化
- 含工具调用/思考块的事件组不折叠，只折叠纯文本连发
- 修复隐藏工具结果后合并连发导致工具调用丢失的问题

## 体验优化

### ✅ 极速加载 + 渐进抛光
- 骨架扫描：启动时仅读取文件元数据，零文件内容读取，百级会话秒开
- 渐进抛光：列表立即可见后，后台逐批（20 个/批）读取文件内容并清洗
- 清洗项：智能标题（去除元数据前缀）、客户端环境检测、消息数统计

### ✅ 智能会话标题
- OpenClaw：去除 `Sender (untrusted metadata):` JSON 块、时间戳行、`[Subagent Task]:` 前缀
- Claude Code VSCode：跳过 `<ide_selection>` 代码选区标记块
- 多 text block 支持：一个 event 含多个 text block 时自动跳过纯元数据块
- 兜底回退：非预期格式保持原文

### ✅ 客户端环境标签
- VSCode / UI / Sub / CLI 四种环境自动识别
- 侧边栏文字标签展示，VSCode 为蓝色、UI 为绿色、Sub 为琥珀色
- CLI（命令行）为默认情况，不显示标签

### ✅ 会话排序增强
- 按创建时间（首条事件时间戳）排序
- 按修改时间（文件系统 mtime）排序
- 支持与路径/名称/消息数/Agent/大小组合二级排序

### ✅ 面板拖拽调整宽度 + 折叠
- 左侧导航面板：右侧边缘拖拽手柄，实时调整宽度（200-600px）
- 右侧轮次导航：左侧边缘拖拽手柄，实时调整宽度（160-400px）
- 左侧导航支持一键折叠/展开为窄条，状态持久化
- 设置中可开关"记住面板宽度"，关闭后拖拽仅当次有效

### ✅ 标签拖拽排序
- 标签栏支持拖拽重排，含插入指示线和拖拽视觉反馈

### 键盘快捷键
- `Ctrl+F` / `Cmd+F` — 聚焦搜索栏
- `Escape` — 关闭设置面板 / 导出对话框
- `↑` `↓` — 在会话列表中切换
- `Ctrl+1/2/3/4` — 切换视图（全部/文件夹/时间线/搜索）

### 导出进度提示
- 导出大文件时显示进度条或 loading 状态
- 导出完成后 toast 提示成功/失败
- 支持取消正在进行的导出

## 会话管理

### 会话删除/归档
- 右键菜单增加"删除会话"选项，确认后删除对应 JSONL 文件
- 支持软删除（移到回收站/归档目录）
- 批量选择删除

### 收藏/标记会话
- 会话列表中可收藏/取消收藏
- 收藏的会话置顶或在独立视图中查看
- 数据持久化到 settings.json 或独立文件

## 视觉增强

### ✅ 暗色模式
- 三种主题：浅色 / 深色 / 护眼，支持跟随系统
- CSS 变量统一主题覆盖，代码块、Markdown 渲染全适配

### ✅ 多标签页
- 顶部标签栏，支持同时打开多个会话
- 标签可关闭、可拖拽排序、可钉住
- 标签页状态持久化，重启后恢复
- 中键/Ctrl+点击在新标签页打开

### ✅ 时间线视图强化
- 时间分组标题：加大加粗、sticky 吸附、Clock 图标、计数药丸
- 组间间距、子项左侧缩进引导线
- 一键折叠/展开全部时间分组

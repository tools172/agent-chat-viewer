# 功能路线图

> ✅ = 已完成，🚧 = 进行中，💡 = 计划中

## 体验优化

### ✅ 极速加载 + 渐进抛光
- 骨架扫描：启动时仅读取文件元数据，零文件内容读取，百级会话秒开
- 渐进抛光：列表立即可见后，后台逐批（20 个/批）读取文件内容并清洗
- 清洗项：智能标题（去除元数据前缀）、客户端环境检测、消息数统计

### ✅ 智能会话标题
- OpenClaw：去除 `Sender (untrusted metadata):` JSON 块、时间戳行、`[Subagent Task]:` 前缀
- Claude Code VSCode：跳过 `<ide_selection>` 代码选区标记块
- 多 text block 支持：一个 event 含多个 text block 时自动跳过纯元数据块
- 兜底回退：非预期格式保持原文

### ✅ 客户端环境标签
- VSCode / UI / Sub / CLI 四种环境自动识别
- 侧边栏文字标签展示，VSCode 为蓝色、UI 为绿色、Sub 为琥珀色
- CLI（命令行）为默认情况，不显示标签

### ✅ 会话排序增强
- 按创建时间（首条事件时间戳）排序
- 按修改时间（文件系统 mtime）排序
- 支持与路径/名称/消息数/Agent/大小组合二级排序

### 会话导航可拖拽调整宽度
- 类似 TurnNavigator 的拖拽手柄，在 SessionNavigator 右侧边缘
- 拖拽时实时调整宽度，松开后存储到设置
- 可替代当前滑块设置，或两者并存

### 键盘快捷键
- `Ctrl+F` / `Cmd+F` — 聚焦搜索栏
- `Escape` — 关闭设置面板 / 导出对话框
- `↑` `↓` — 在会话列表中切换
- `Ctrl+1/2/3/4` — 切换视图（全部/文件夹/时间线/搜索）

### 导出进度提示
- 导出大文件时显示进度条或 loading 状态
- 导出完成后 toast 提示成功/失败
- 支持取消正在进行的导出

---

## 会话管理

### 会话删除/归档
- 右键菜单增加"删除会话"选项，确认后删除对应 JSONL 文件
- 支持软删除（移到回收站/归档目录）
- 批量选择删除

### 收藏/标记会话
- 会话列表中可收藏/取消收藏
- 收藏的会话置顶或在独立视图中查看
- 数据持久化到 settings.json 或独立文件

---

## 视觉增强

### 暗色模式
- 全局暗色主题切换（跟随系统 / 手动切换）
- Tailwind 的 `dark:` 前缀可原生支持
- 代码块、Markdown 渲染适配暗色

### 多标签页
- 顶部标签栏，支持同时打开多个会话
- 点击会话列表时新建标签而非替换
- 标签可关闭、可拖拽排序

---

## 数据洞察

### 会话统计面板
- 工作目录维度：总会话数、总消息数
- 时间维度：会话频率趋势图
- Agent 维度：各 Agent 使用占比

### Token 用量估算
- 基于消息内容长度粗略估算 Token 数
- 会话列表显示估算 Token 用量
- 工作目录/Agent 维度汇总
